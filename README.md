# Tic-Tac-Toe Game

A classic, interactive, and fully responsive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. Playable for two players on the web with real-time win/draw detection and a clean user interface.

## 🚀 Live Demo


## 🛠️ Built With
* **HTML5:** For game board structure and layout.
* **CSS3:** For styling, grid alignment, and visual appeal.
* **JavaScript (ES6):** For game logic, turn management, and win/draw condition checking.

## ✨ Features
* **Two-Player Mode:** Play locally with a friend (X and O turns).
* **Interactive UI:** Smooth clicks with clear visual indicators for active turns and winning moves.
* **Reset Functionality:** Option to restart the game at any point without refreshing the page.
* **Winner & Draw Alerts:** Instant notification when a player wins or the match ends in a draw.
